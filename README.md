# Plateforme de réservation de rendez-vous

## Stack technique
- Frontend : React + Vite + MUI (ou Tailwind)
- Backend : Node.js + Express + Prisma + PostgreSQL + Zod

## Structure du projet
- `backend/` : code de l’API, gestion des données, logique métier
- `frontend/` : interface utilisateur, consommation de l’API

## Démarrage rapide

### Backend
```bash
cd backend
npm install
npm run dev
